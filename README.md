# Linux System Health Monitoring

## Project Description
A beginner DevOps project using Bash scripting
to monitor Linux system health.

## Tools Used
- Ubuntu Linux
- Bash Scripting
- WSL2
- Linux Commands

## Features
- Displays date and time
- Checks system uptime
- Monitors CPU usage
- Displays memory usage
- Checks disk usage
- Lists running processes
- Generates a health report

## How to Run

1. Open the Ubuntu terminal.
2. Navigate to the project folder.
3. Run:

   ./system_monitor.sh

## Generate Report

./system_monitor.sh | tee health_report.txt
